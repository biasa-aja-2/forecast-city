The weather forecast for Grumblwick, a city that does not exist:

> Forecast for Grumblwick: drizzle of lost socks at 14 degrees, clearing by noon; umbrellas useless, laundry baffled.

Flat bulletin phrasing that breaks with absurd weather: lost socks drizzle over the invented city Grumblwick, concrete numbers (14 degrees, clearing by noon), and a deadpan kicker — umbrellas useless, laundry baffled. The joke comes from the weather itself.

Pure Python stdlib, no network, no secrets. `main.py` writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and
verifies it byte-for-byte against a self-check gate (1–120 characters,
single line, exactly one sentence).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
